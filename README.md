# LuckyDraw 🎲

Egyszerű, túrázás témájú nyereményjáték ASP.NET Core Razor Pages alkalmazásban.

## A projektről

A projekt egy C# gyakorlásként készült mini webalkalmazás, amely véletlenszerű szám alapján sorsol nyereményt.

A főnyeremény egy kétszemélyes utazás, amely csak egyszer nyerhető meg. Egy felhasználó egy munkamenetben egyszer sorsolhat.

## Funkciók

- véletlenszerű szám generálása 1 és 100 között
- különböző nyeremények a generált szám alapján
- egyszeri főnyeremény
- Session alapú sorsoláskezelés
- nyereményekhez kapcsolódó képek

## Használt technológiák

- C#
- ASP.NET Core
- Razor Pages
- HTML
- CSS
- ASP.NET Core Session
